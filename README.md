## 🚀 Tecnologias Utilizadas

### Frontend
- **HTML5** - Estrutura semântica e acessível
- **CSS3** - Estilização personalizada com animações
- **Bootstrap 5** - Sistema de grid e componentes responsivos
- **Bootstrap Icons** - Biblioteca de ícones

### Bibliotecas e Animações
- **GSAP** - Animações avançadas e efeitos de scroll
- **ScrollTrigger** - Animações acionadas por scroll
- **AOS (Animate On Scroll)** - Animações de entrada suaves
- **Three.js** - Renderização 3D do sol e efeitos de fundo

### Recursos Adicionais
- **Google Fonts (Inter)** - Tipografia moderna
- **Unsplash** - Imagens de alta qualidade
